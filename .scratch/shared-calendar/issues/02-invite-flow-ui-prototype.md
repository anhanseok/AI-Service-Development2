## Question

공유 캘린더의 핵심 화면과 초대 플로우가 실제로 어떻게 보이고 동작해야 하는지, 러프한 프로토타입으로 확인한다.

다뤄야 할 화면:
- 로그인/회원가입 (Supabase Auth)
- 내 캘린더 목록
- 캘린더 상세 (월간 뷰)
- 일정 생성/수정 모달
- 멤버 초대 모달 (이메일 입력 → 가입된 사용자만 초대 가능, 미가입자면 에러 표시)
- 캘린더 멤버 목록 및 권한 표시

`prototype` 스킬을 호출해 러프한 화면 stub이나 목업을 만들고, 이 티켓에 링크로 남긴다.

## Answer

**Variant A(사이드바 리스트-상세) 채택.** 왼쪽 사이드바에 내가 속한 캘린더 목록, 오른쪽 본문에 선택된 캘린더의 월간 뷰. 캘린더 전환이 항상 한 클릭이고 여러 캘린더를 동시에 인지할 수 있어서, 카드 대시보드(B, 상세 진입 시 목록이 사라짐)나 탭(C, 캘린더가 늘면 탭이 좁아짐)보다 이 앱의 "여러 공유 캘린더를 오간다"는 성격에 맞음.

추가로 확정된 요구사항 — **일정에 시간 표시 필수**:
- 월간 뷰 셀의 일정 항목은 `시작시간 + 제목` 형태로 표시하고 시작시간순 정렬 (예: `10:30 병원 예약`)
- 일정 생성/수정 폼은 날짜 외에 **시작 시간 / 종료 시간** 입력을 가짐
- 01번 티켓의 `Event.startAt` / `Event.endAt`(DateTime)이 이 요구사항을 이미 만족 — 스키마 변경 불필요

화면 구성 확정:
- 로그인/회원가입: 이메일 + 비밀번호 단일 카드 폼
- 사이드바: 내 캘린더 목록 + "새 캘린더" 버튼
- 본문 헤더: 캘린더 이름 + "멤버 초대 (N)" 버튼
- 월간 뷰: 7열 그리드, 빈 날짜 클릭 → 일정 추가 모달(날짜 프리필), 일정 클릭 → 수정 모달(삭제 버튼 포함)
- 초대 모달: 이메일 입력 → 가입자면 성공 메시지, 미가입자면 "가입된 사용자만 초대할 수 있습니다" 에러 + 현재 멤버 목록 표시

프로토타입 코드: `src/app/prototype/shared-calendar/page.tsx` (throwaway route). 사용자 결정으로 06번 구현 시 참고하기 위해 당분간 main에 남겨둠 — **06/07번 티켓 완료 후 이 라우트 삭제할 것**.
