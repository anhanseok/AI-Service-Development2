# 03: 운영자가 투표 만들기

**만들 것:** 로그인한 운영자가 질문, 선택지 2~6개, 한국 시간(KST) 마감 시간으로 투표를 만든다. 새 투표는 첫 화면에 나타난다. 잘못된 입력은 분명한 메시지와 함께 거부된다. 투표자는 만들기 화면에 들어가거나 만들기 동작을 호출할 수 없다.

**먼저 끝나야 할 티켓:** 02

- [x] 도메인 검사: 빈 질문 거부, 선택지 2개 미만 또는 6개 초과 거부, 빈/중복 선택지 거부, 만들 때 과거 마감 시간 거부
